# Python - Everything is Object

This project explores Python objects, references, aliases,
mutable and immutable objects, and how variables are passed
to functions.

## Tasks

- 0-18: Questions about objects, identity, equality and mutation.
- 19: Create a copy of a list.
- 20-28: Questions about tuples, identity and list operations.
- 29: Blog post about Python objects.

## Requirements

- Python 3.8.5
- Ubuntu 20.04 LTS
- Pycodestyle 2.7.*
