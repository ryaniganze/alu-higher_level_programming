# Python - Network #0

This project introduces HTTP requests and the use of cURL
from Bash scripts.

## Tasks

- 0-body_size.sh: Display the size of an HTTP response body.
- 1-body.sh: Display the body of a successful GET request.
- 2-delete.sh: Send a DELETE request and display its response.
- 3-methods.sh: Display HTTP methods accepted by a server.
- 4-header.sh: Send a GET request with a custom HTTP header.
- 5-post_params.sh: Send POST parameters to a URL.

## Requirements

- Ubuntu 20.04 LTS
- Bash scripts must contain exactly 3 lines.
- First line: #!/bin/bash
- Second line: a comment explaining the script.
- All curl commands must use -s.
- Files must end with a newline.
- Scripts must be executable.
