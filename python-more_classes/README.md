# Python - More Classes and Objects

This project introduces advanced object-oriented programming concepts
in Python.

## Tasks

- 0-rectangle.py: Create an empty Rectangle class.
- 1-rectangle.py: Add width and height properties with validation.
- 2-rectangle.py: Add area and perimeter methods.
- 3-rectangle.py: Add string representation.
- 4-rectangle.py: Add a representation that supports eval().
- 5-rectangle.py: Detect instance deletion.
- 6-rectangle.py: Count the number of instances.
- 7-rectangle.py: Change the string representation symbol.
- 8-rectangle.py: Compare two rectangles.
- 9-rectangle.py: Create a square using a class method.

## Requirements

- Python 3.8.5
- Ubuntu 20.04 LTS
- Pycodestyle 2.7.*
