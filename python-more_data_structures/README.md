# Python - More Data Structures: Set, Dictionary

This project covers Python sets, dictionaries, and functional programming.

## Learning Objectives

- Understand sets and their methods.
- Understand dictionaries and their methods.
- Iterate through sets and dictionaries.
- Understand lambda functions.
- Use map, filter, and reduce.
