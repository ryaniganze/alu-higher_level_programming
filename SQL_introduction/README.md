# SQL - Introduction

This project introduces relational databases and basic SQL queries
using MySQL 8.0.

## Tasks

- 0-list_databases.sql: List all databases.
- 1-create_database_if_missing.sql: Create a database if it does not exist.
- 2-remove_database.sql: Delete a database if it exists.
- 3-list_tables.sql: List all tables in a database.
- 4-first_table.sql: Create the first_table table.
- 5-full_table.sql: Display the full table creation statement.
- 6-list_values.sql: List all rows in first_table.
- 7-insert_value.sql: Insert a new record into first_table.
- 8-count_89.sql: Count records with id 89.
- 9-full_creation.sql: Create second_table and insert records.
- 10-top_score.sql: List records ordered by score.
- 11-best_score.sql: List records with score >= 10.
- 12-no_cheating.sql: Update Bob's score.
- 13-change_class.sql: Remove records with score <= 5.
- 14-average.sql: Calculate the average score.
- 15-groups.sql: Count records with the same score.
- 16-no_link.sql: List named records ordered by score.

## Requirements

- Ubuntu 20.04 LTS
- MySQL 8.0
- SQL keywords in uppercase
- Comments before SQL queries
- Files end with a newline
