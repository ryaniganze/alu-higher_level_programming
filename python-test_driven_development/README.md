# Python - Test-driven Development

This project introduces test-driven development using Python doctest
and unittest.

## Tasks

- 0-add_integer.py: Add two integers.
- 2-matrix_divided.py: Divide every element of a matrix.
- 3-say_my_name.py: Print a person's full name.
- 4-print_square.py: Print a square using #.
- 5-text_indentation.py: Print text with indentation after punctuation.
- tests/6-max_integer_test.py: Test the max_integer function using unittest.

## Running doctests

python3 -m doctest ./tests/*

## Running unit tests

python3 -m unittest tests.6-max_integer_test

## Requirements

- Python 3.8.5
- Ubuntu 20.04 LTS
- Python files start with #!/usr/bin/python3
- Python files are executable.
- All files end with a newline.
- Use meaningful module and function documentation.
