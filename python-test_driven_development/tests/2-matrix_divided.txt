The matrix_divided function
===========================

This function divides each matrix value and rounds the result to two decimals.

Basic division:

>>> matrix = [[1, 2, 3], [4, 5, 6]]
>>> matrix_divided(matrix, 3)
[[0.33, 0.67, 1.0], [1.33, 1.67, 2.0]]

The original matrix is not changed:

>>> matrix
[[1, 2, 3], [4, 5, 6]]

Division by a float:

>>> matrix_divided([[1, 2], [3, 4]], 0.5)
[[2.0, 4.0], [6.0, 8.0]]
