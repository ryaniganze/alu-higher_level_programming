The print_square function
=========================

This function prints a square using the # character.

A square with side length three:

>>> print_square(3)
###
###
###

A square with side length one:

>>> print_square(1)
#

A zero-sized square prints nothing:

>>> print_square(0)

A negative size raises ValueError:

>>> print_square(-1)
Traceback (most recent call last):
...
ValueError: size must be >= 0

A non-integer size raises TypeError:

>>> print_square("3")
Traceback (most recent call last):
...
TypeError: size must be an integer
