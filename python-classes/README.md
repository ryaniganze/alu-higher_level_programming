# Python - Classes and Objects

This project introduces object-oriented programming in Python.

## Tasks

- 0-square.py: Create an empty Square class.
- 1-square.py: Add a private size attribute.
- 2-square.py: Add size validation.
- 3-square.py: Add a method to calculate the area.
- 4-square.py: Add a getter and setter for size.
- 5-square.py: Add a method to print the square.
- 6-square.py: Add position validation and printing position.

## Requirements

- Python 3.8.5
- Ubuntu 20.04 LTS
- Pycodestyle 2.7.*
