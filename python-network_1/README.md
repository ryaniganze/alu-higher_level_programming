# Python - Network #1

This project explores HTTP requests using Python's urllib and
requests packages.

## Tasks

- 0-hbtn_status.py: Fetch a resource using urllib.
- 1-hbtn_header.py: Display the X-Request-Id response header.
- 2-post_email.py: Send an email using an urllib POST request.
- 3-error_code.py: Handle HTTP errors using urllib.
- 4-hbtn_status.py: Fetch a resource using requests.
- 5-hbtn_header.py: Display the X-Request-Id using requests.
- 6-post_email.py: Send an email using requests.
- 7-error_code.py: Handle HTTP errors using requests.
- 8-json_api.py: Send a search request and process JSON.
- 10-my_github.py: Display a GitHub user's ID using Basic Authentication.

## Requirements

- Python 3.4.3 compatibility.
- First line: #!/usr/bin/python3
- Executable Python files.
- Module documentation.
- PEP 8 style.
- Scripts must not execute when imported.
