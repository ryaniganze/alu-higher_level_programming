# Python - Input/Output

This project introduces file handling and JSON in Python.

## Tasks

- 0-read_file.py: Read and print a text file.
- 1-write_file.py: Write text to a file.
- 2-append_write.py: Append text to a file.
- 3-to_json_string.py: Convert an object to a JSON string.
- 4-from_json_string.py: Convert a JSON string to a Python object.
- 5-save_to_json_file.py: Save an object to a JSON file.
- 6-load_from_json_file.py: Load an object from a JSON file.
- 7-add_item.py: Add command-line arguments to a JSON list.
- 8-class_to_json.py: Convert an object's attributes to a dictionary.
- 9-student.py: Create a Student class.
- 10-student.py: Add attribute filtering to Student.
- 11-student.py: Add JSON reload functionality to Student.
- 12-pascal_triangle.py: Generate Pascal's Triangle.

## Requirements

- Python 3.8.5
- Ubuntu 20.04 LTS
- Pycodestyle 2.7.*
