# Python - Inheritance

This project introduces inheritance and object-oriented programming
in Python.

## Tasks

- 0-lookup.py: List the attributes and methods of an object.
- 1-my_list.py: Create a list subclass with sorted printing.
- 2-is_same_class.py: Check the exact class of an object.
- 3-is_kind_of_class.py: Check an object's class and inheritance.
- 4-inherits_from.py: Check whether an object inherits from a class.
- 5-base_geometry.py: Create an empty BaseGeometry class.
- 6-base_geometry.py: Add the area method.
- 7-base_geometry.py: Add integer validation.
- 8-rectangle.py: Create a Rectangle class.
- 9-rectangle.py: Implement the full Rectangle class.
- 10-square.py: Create a Square class.
- 11-square.py: Add a string representation to Square.

## Requirements

- Python 3.8.5
- Ubuntu 20.04 LTS
- Pycodestyle 2.7.*
- Doctest files are stored in the tests directory.
