# SQL - More Queries

This project explores more advanced SQL and MySQL concepts.

## Tasks

- 0-privileges.sql: List MySQL user privileges.
- 1-create_user.sql: Create a MySQL user with all privileges.
- 2-create_read_user.sql: Create a database and read-only user.
- 3-force_name.sql: Create a table with a NOT NULL constraint.
- 4-never_empty.sql: Create a table with a default ID.
- 5-unique_id.sql: Create a table with a unique ID.
- 6-states.sql: Create a states table with a primary key.
- 7-cities.sql: Create a cities table with a foreign key.
- 8-cities_of_california_subquery.sql: List California cities using a subquery.
- 9-cities_by_state_join.sql: List cities and their states.
- 10-genre_id_by_show.sql: List shows with linked genre IDs.
- 11-genre_id_all_shows.sql: List all shows and their genre IDs.
- 12-no_genre.sql: List shows without a genre.
- 13-count_shows_by_genre.sql: Count shows linked to each genre.
- 14-my_genres.sql: List the genres of Dexter.
- 15-comedy_only.sql: List Comedy shows.
- 16-shows_by_genre.sql: List all shows and their genre names.

## Requirements

- Ubuntu 20.04 LTS
- MySQL 8.0
- SQL keywords in uppercase
- Comments before SQL queries
- Files end with a newline
